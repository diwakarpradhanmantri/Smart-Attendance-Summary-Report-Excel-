# 📊 Smart Attendance Summary Report (Excel)

## 📌 Project Overview  
This project provides a **smart attendance management system in Excel** that helps track and summarize daily attendance records of multiple students over a semester.  

The system automatically calculates **attendance percentages**, highlights students with **less than 75% attendance**, and generates insightful **dashboards and trend charts** for better monitoring.  

---

## 🎯 Features  
- ✅ Record daily attendance (Present/Absent) for multiple students  
- ✅ Automatically calculate total presents using `COUNTIF`  
- ✅ Compute overall **attendance percentage** for each student  
- ✅ Highlight students with **<75% attendance** using conditional formatting  
- ✅ Generate **line charts** to analyze weekly attendance trends  
- ✅ Interactive **dashboard** to view attendance summaries & alerts  

---

## 📂 Functional Components  
- **Columns:** Date, Student Name, Status (P/A)  
- **Formulas Used:** `COUNTIF`, percentage calculation  
- **Visualization:** Line charts, conditional formatting  
- **Alerts:** Automatic highlighting for defaulters (<75%)
